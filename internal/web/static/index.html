Cada conexão é um banco que a IA enxerga. Consultas de leitura estão sempre liberadas; escrever exige a permissão ligada aqui.

    O que a IA enxerga
    
      
    As ferramentas são montadas a partir das conexões ativas. sql_query lista só conexões SQL; sql_execute só aparece quando alguma conexão SQL tem escrita liberada; as ferramentas mongo_* listam só conexões MongoDB.
    
      
    Cada conexão vai com o tipo, o dialeto, o estilo de parâmetro e a descrição. É a descrição que faz a IA escolher a conexão certa: diga o que há naquele banco.
    
      
    Clientes que guardam a lista de ferramentas podem precisar reconectar depois de uma mudança aqui. As permissões, porém, são conferidas a cada chamada.
