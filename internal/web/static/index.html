O que a LLM enxerga

      
As ferramentas são montadas a partir das conexões ativas: sql_query só lista conexões SQL, sql_execute só aparece para conexões com alguma escrita liberada, e as ferramentas mongo_* só listam conexões MongoDB. Cada conexão vai com tipo, dialeto, estilo de parâmetro e descrição — capriche na descrição para a LLM escolher a conexão certa. Clientes que guardam a lista de ferramentas em cache podem precisar reconectar após mudanças; as permissões, porém, são checadas a cada chamada.
